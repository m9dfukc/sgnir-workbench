# Lexicon (Deutsch ↔ English)

Term mapping for this project. The imported reference material in `reference/schliere-owl/` and
the origin project `acdc-workbench` are written in German; all new artifacts here are English.
Keep this table current when translating.

| Deutsch | English | Notes |
|---|---|---|

| Abgriff | tap | pick-off point in the allpass chain |
| Kette | chain | the chain of 61 second-order allpasses |
| Stufe | stage | one second-order allpass (2 poles) |
| Rastpunkt | detent | the 7 snap positions of the tap knob |
| Überblendung | crossfade | between two taps |
| Haltezone | hold zone | region around a detent where the tap stays put |
| Totzone | dead zone | CV region around 0 V with no effect |
| Knie | knee | soft-limiting knee (of the tanh/SoftClip curve) |
